## Overview

Analyzed X-Ray Fluorescence (XRF) spectroscopic data from the Chandrayaan-2 Lunar Crater Instrument for Compositional Analysis (CLASS) to map elemental composition across lunar surface features.

## Key Contributions

- **Data Processing**: Cleaned and processed ~500GB of raw XRF spectroscopic data
- **Elemental Mapping**: Generated element abundance maps for major lunar minerals (Fe, Ti, Si, Al)
- **Spectral Analysis**: Identified rare earth element (REE) concentrations in specific lunar regions
- **Visualization**: Created publication-quality maps showing correlation with crater morphology

## Technologies Used

- Python (NumPy, SciPy, Matplotlib)
- Spectroscopic data analysis
- Geospatial visualization
- Machine learning for anomaly detection

## Results

- Successfully mapped 15+ elements across study regions
- Identified areas of scientific interest for future lunar missions
- Contributed to understanding lunar resource potential
